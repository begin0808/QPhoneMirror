【快速開始】

1. 在資料夾內點兩下「QPhoneMirror.exe」啟動程式（電腦免裝 Python）。
2. 左下角「主題風格」可即時切換三套配色：
   櫻花薄荷・可愛清新 / 森林燕麥・北歐清新 / 星空軟糖・柔和夜色

【Android 安卓手機投影與快捷工具】
------------------------------------------------------------
• 首次開啟若尚未安裝核心，按下畫面上的「一鍵下載並安裝核心」即可自動完成下載。
• 有線投影與自動感應連線：
  1. 於手機開啟「開發人員選項 → USB 偵錯」（程式內「操作說明」附詳細步驟）。
  2. 接上 USB 傳輸線，程式會自動感應手機（亦可手動按下「掃描手機」），接著按下「開始投影」即可同步畫面並用電腦滑鼠鍵盤操作。
• Wi-Fi 無線投影（兩種方式）：
  - 插線轉無線：插線偵測到手機後按下「插線轉無線」，成功後即可拔線進行無線投影。
  - 免插線配對碼（Android 11 以上）：按下「免插線配對碼設定」，輸入手機無線偵錯的配對 IP:連接埠與 6 位數配對碼，完全不須傳輸線即可完成無線連線。
• 截圖、同步錄影、無線傳檔與虛擬遙控：
  - 按下「手機畫面截圖」可立即儲存 PNG 至 captures 資料夾。
  - 開啟「投影時同步錄製 MP4 影片」可在投影同時錄製手機純畫面並自動存檔。
  - 按下「傳送檔案 / 安裝 APK」可透過有線或 Wi-Fi 無線傳檔至手機「下載 (Download)」資料夾（.apk 會自動安裝）。
  - 虛擬遙控列可直接操作返回、主畫面、多工切換、音量與螢幕開關。
• 免開啟 USB 偵錯模式與安全提醒：
  - 若不想開啟手機開發人員選項，或不想受銀行／股票 App 的 USB 偵錯提醒干擾，可按下「開啟無線投影接收」啟動 Windows 無線投影，再從手機下拉選單點選無線投影或 Smart View 即可。
  - 若使用 USB 偵錯模式，建議平常不投影時關閉「USB 偵錯」，僅在自己的私人電腦勾選「一律允許」，並避免在公共 Wi-Fi 開啟「無線偵錯」。

【Apple iPhone / iPad 投影】（AirPlay）
------------------------------------------------------------
1. 確認 iPhone / iPad 與電腦連接同一個 Wi-Fi 網路。
2. 切換至「蘋果 AirPlay」分頁，首次使用按下「一鍵下載並安裝核心」即可自動下載攜帶版核心（內建 mDNS，免額外安裝 Bonjour）。
3. 按下「開啟 AirPlay 接收服務」啟動接收器。
4. 由 iPhone / iPad 右上角下滑開啟「控制中心」→ 點選「螢幕鏡像輸出」→ 選擇這台電腦即完成連線。

------------------------------------------------------------
【高畫質電腦螢幕錄影】（不限手機投影時使用）
------------------------------------------------------------
1. 切換至左側「電腦螢幕錄影」分頁，首次使用按下「一鍵下載並安裝核心」自動下載 FFmpeg。
2. 支援三種錄影範圍：「全螢幕錄製」、「指定程式視窗錄製（防黑畫面）」與「滑鼠框選錄影區域」。
3. 支援「錄製電腦系統聲音（預設關閉）」與「錄製麥克風旁白」雙軌混音，並提供「極致／標準／輕量」白話畫質選項與「變更儲存資料夾」。
4. 按下「開始電腦螢幕錄影」，錄製完成後按下「停止並儲存 MP4」即可安全存檔。
